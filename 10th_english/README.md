# Lucas's Grade-10 English Project — Start Here

A problem/question-driven study system for Lucas's sophomore English class (Foothill HS, Mrs. Pagtakhan). **Goal: understand everything before the class starts and earn an A** — efficiently, in a few weeks of focused work, without slowly reading every page. Same architecture as the CSA system (in `../ap_csa/`), adapted because English is learned differently: **read → analyze → write → rubric-feedback → discuss**, not drill-the-one-right-answer.

## What's here

## How to run it
1. Set up the tutor: follow **`chatgpt-setup.md`** (paste `tutor-prompt.md` as instructions; upload `coverage-map.md`, `mastery-tracker.md`, and all of `study-packs/` + `guides/` + `reference/`).
2. Lucas types **"let's start"** → short diagnostic → then **"let's continue"** each day (~30–40 min).
3. Paste the end-of-session `TRACKER UPDATE` into `mastery-tracker.md`.

## Strategy in one breath
**Essay writing first** (it lifts every essay grade), then the study pack for the next book, then keep vocab + homework airtight for free points, and use the unit-exam self-quizzes to ace the reading tests. The tutor **coaches and quizzes — it never writes his essays** (the teacher bans AI work and checks turnitin.com; the A has to be real).

## How this was built
Built from the actual class website (monthly agendas Aug–May, reading schedule, the teacher's essay prompts + editing checklist + RIP-words rubric, vocab lists, and device/grammar lessons), cross-checked with an independent fact-checked research pass on all five texts. **5 docs were login-walled** (Sept + Mar agendas, Reading Schedule, Life-of-Pi Socratic FRQs, the removed Narrative prompt) and were reconstructed from surrounding weeks — drop them in if you obtain them.
